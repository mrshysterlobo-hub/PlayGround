Turn the plan into a real runner

        

        ADB + Computer vision
      


      

        

          01
          
Arm a test device

          
Use an emulator or a spare phone with USB debugging enabled. Keep the game in a fixed resolution and language.

          adb devices
        

        

          02
          
Capture screen states

          
Store reference crops for the city, world map, queues, and popups. Match with a confidence threshold before every tap.

          adb exec-out screencap -p
        

        

          03
          
Drive the loop

          
Feed this JSON to an ADB / uiautomator runner. Add jitter, retries, and a hard stop whenever the screen is unknown.

          uiautomator dump
        

        

          04
          
Observe and pause

          
Stream screenshots to a local dashboard, log every action, and keep a physical kill switch within reach.

          adb shell input tap X Y
